# OneCielAI Redesign v1

Fresh-start logo directions for OneCielAI.

Brand name: OneCielAI

Legal/company name: One Ciel LLC

## Concepts

1. Ciel Window - Calm brand portal, good for YouTube/channel identity.
2. Sky Bridge - Connected projects under one sky.
3. Aurora Grid - More technical and energetic, good for developer content.
4. Cloud Kernel - Cloud/AI product family direction.
5. Orbitless Wordmark - Clean corporate wordmark direction.
6. One Horizon Seal - Simple, friendly social mark.
7. Starlight Console - Developer tooling and terminal-native identity.
8. Zenith AI - Upward, ambitious, product-studio direction.

Recommended starting pairs:

- Channel avatar: 01 Ciel Window or 06 One Horizon Seal.
- Developer tooling visuals: 07 Starlight Console.
- Corporate wordmark: 05 Orbitless Wordmark.
- Cloud/AI product family: 04 Cloud Kernel.
