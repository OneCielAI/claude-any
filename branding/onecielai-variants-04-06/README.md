# OneCielAI Variants: Cloud Circuit + Minimal Wordmark

Focused expansion of earlier concept 04 and 06.

Brand name: OneCielAI

Legal/company name: One Ciel LLC

## Best Uses

- **04A Clean Cloud Circuit Badge**: strong channel/avatar candidate; keeps the
  cloud AI meaning while staying compact.
- **04D Cloud Signal Infra**: best for infrastructure, server, cloud, and ops
  products.
- **04E Premium Cloud Chip**: premium dark icon candidate; good for app icons
  and video corner marks.
- **06A Clean Orbit Wordmark**: best all-purpose official wordmark for banners,
  GitHub cards, and video intros.
- **06D Split Ciel Wordmark**: best when the brand meaning of `Ciel` should be
  emphasized.
- **06F OC Social Mark**: useful as a simple social/profile fallback when the
  full `OneCielAI` wordmark is too wide.

## Notes

Use cloud/circuit variants for project icons and product-family visuals. Use
wordmark variants for channel art, thumbnails, GitHub organization assets, and
documents.

The 98px preview sheet helps check YouTube/profile readability.
