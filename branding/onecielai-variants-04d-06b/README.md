## Recommended Uses

- **04D-6 Profile Signal Icon**: strongest YouTube profile/avatar candidate.
  It removes small wordmark clutter and keeps the cloud signal symbol readable.
- **04D-1 Cloud Signal Badge**: good general icon when the OneCielAI wordmark
  should still appear.
- **04D-3 Cloud Router Signal**: best for infrastructure, router, server, and
  developer tooling projects.
- **06B-1 Dark Capsule Wordmark**: best official banner/intro wordmark.
- **06B-4 Dark OC Lockup**: good for YouTube thumbnails and organization cards.
- **06B-6 Dark OC Seal**: good compact social/profile fallback.
